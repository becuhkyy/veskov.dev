PROJECTS -----------------------------------------------------------------------

  bvf-platform
      The Bulgarian Volleyball Federation's competition system, end to end. It
      handles Berger schedule generation, championship and team management, and
      match document generation. Referees run the live-scoring PWA court-side,
      on a dependency-free, offline-tolerant scoring engine.
      stack   typescript, strapi 5, react 19, pwa, playwright
      source  https://github.com/becuhkyy/bvf-livescore
      note    live-scoring source is public; the rest is private

  bvf-registry
      The federation's electronic licence system for clubs, players, coaches,
      licences, transfers, halls and season applications, feeding both the admin
      SPA and the public register on bvf.bg. In production since 2025.
      stack   c# / .net 10, ef core, sql server, react 19, tanstack query
      live    https://db.bvf.bg
      note    private repo, client system

  pushdb
      Database backup orchestration SaaS, born from running backup-heavy hosting
      infrastructure for a decade. Monorepo with a web app, a scheduler and a
      worker, containerised and deployed to k8s.
      stack   typescript, tanstack start, postgres, docker, kubernetes
      note    private repo, work in progress

  notabene-suite
      Systems for the Nota Bene pharmacy chain and its medical laboratory. The
      core is an order and patient journal, plus a cash-flow book that spans
      registers, safes and transfers across shops. Underneath it, a service
      exposes the legacy Firebird databases over a clean REST API, and a
      stubborn Python bot retries a flaky national export until it gets a
      complete one.
      stack   next.js, nestjs, prisma, postgresql, firebird, python
      note    private repos, client work

  nestjs-portfolio
      A set of services built to production patterns rather than tutorial
      patterns: reservations with payments, task management, a GraphQL API, and
      an AI microservice, all with DI, tests and containers throughout.
      stack   typescript, nestjs, graphql, mongodb, next.js
      source  https://github.com/becuhkyy?tab=repositories&q=nestjs
